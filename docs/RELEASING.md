# Release Procedure

This document specifies the release procedure for Offline Code Context Compiler (OCC). Releases are published as version-tagged `.vsix` binaries attached to GitHub releases.

## Core Release Invariant

Published git tags are never moved or deleted. If a defect is discovered in a published release, the fix must be committed to `main` and published as a new patch release version.

## Step-by-Step Release Workflow

### 1. Version Bump and Changelog
1. Create a release branch off `main`: `git checkout -b release/v0.x.y`.
2. Update the `version` field in `package.json`.
3. Update `CHANGELOG.md`:
   - Rename the `## [Unreleased]` section to `## [0.x.y] - YYYY-MM-DD`.
   - Add a fresh, empty `## [Unreleased]` section above it.
   - Summarize additions, changes, fixes, and security updates following Keep a Changelog format.
4. Run documentation synchronization and verification:
   ```bash
   npm run test:docs-sync
   ```

### 2. Local Verification Battery
Run the full verification battery locally:

```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npm run test:docs-sync
npm run compile
```

Commit the version bump and changelog updates:
```bash
git commit -am "chore(release): bump version to 0.x.y"
```

### 3. CI Matrix Run on GitHub
1. Push the release branch to GitHub and open a pull request into `main`.
2. Merge the release pull request into `main`.
3. Await completion of the GitHub Actions CI matrix on the merge commit on `main`. CI builds across Ubuntu, macOS, and Windows runners, running tests and generating the release package artifact.

### 4. Download and Verify CI Package Artifact
Do not distribute locally packaged binaries. Distribute the verified build artifact generated by GitHub Actions:

1. Navigate to the GitHub Actions run for the release commit on `main`.
2. Download the `vsix-ubuntu-latest` artifact archive and extract `offline-code-context-compiler-0.x.y.vsix`.
3. Calculate and record the SHA-256 checksum of the downloaded file:
   - Linux/macOS: `sha256sum offline-code-context-compiler-0.x.y.vsix`
   - Windows PowerShell: `Get-FileHash offline-code-context-compiler-0.x.y.vsix -Algorithm SHA256`
4. Run the clean-profile smoke test against the exact downloaded file:
   ```bash
   npm run smoke:vsix -- "/path/to/offline-code-context-compiler-0.x.y.vsix"
   ```
5. Perform manual verification in VS Code:
   - Install the `.vsix` archive: `code --install-extension offline-code-context-compiler-0.x.y.vsix`.
   - Open a test workspace (such as `demo-project`).
   - Run `OCC: Generate Task Context` and verify that the preview opens and generates expected content.
   - Run `OCC: Copy Context to Clipboard` and verify that content copies cleanly to the clipboard.

### 5. Tagging and GitHub Release
1. Create a signed, annotated git tag on the release commit:
   ```bash
   git tag -a v0.x.y -m "Release v0.x.y"
   git push origin v0.x.y
   ```
2. Attach the verified `.vsix` binary to the GitHub Release. Use either the GitHub web interface or the GitHub CLI with an explicit personal access token. Never read credentials from a git credential helper.
   - Web UI: Navigate to `https://github.com/SpEXterXD/Code-Context/releases/new`, select tag `v0.x.y`, paste release notes, and upload the `.vsix` file.
   - GitHub CLI:
     ```bash
     $env:GH_TOKEN = "your-personal-access-token"
     gh release create v0.x.y "offline-code-context-compiler-0.x.y.vsix" --title "v0.x.y" --notes-file RELEASE_NOTES.md
     ```

## Marketplace and Open VSX Checklist

When the publisher account is registered, publish to public registries using this checklist:

### Prerequisites
- [ ] Marketplace publisher account created at `https://marketplace.visualstudio.com/manage`.
- [ ] Publisher ID configured in `package.json` under `"publisher"`.
- [ ] High-resolution extension icon (128x128 PNG) placed at `images/icon.png` and referenced in `package.json`.
- [ ] Personal Access Token (PAT) generated with `Marketplace (Manage)` scope.
- [ ] Open VSX access token generated at `https://open-vsx.org`.

### Publication Steps
1. Verify package manifest contents:
   ```bash
   npx @vscode/vsce ls
   ```
2. Publish to Visual Studio Marketplace:
   ```bash
   npx @vscode/vsce publish --pat "YOUR_MARKETPLACE_PAT"
   ```
3. Publish to Open VSX Registry:
   ```bash
   npx ovsx publish "offline-code-context-compiler-0.x.y.vsix" --pat "YOUR_OPENVSX_PAT"
   ```
4. Update `README.md` to add Marketplace badge and install link.
